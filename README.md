# Hospital Emergency Department Analytics Dashboard

## Project Overview
This project uses Power BI to analyze a synthetic hospital emergency department dataset containing 2,500 patient encounters. The dashboard explores patient volume, waiting times, length of stay, admission rates, and acuity levels.

The purpose is to demonstrate data analysis, SQL, data visualization, and dashboard development skills using illustrative healthcare data.

## Tools and Technologies
- Power BI Desktop — interactive dashboard development
- PostgreSQL and SQL — data preparation and analysis
- PowerShell — supporting data workflow
- DAX — KPI measures
- GitHub — project documentation and version control

## Dashboard KPIs
| Metric | Result |
| --- | --- |
| Total ED Encounters | 2,500 |
| Average ED Wait Time | 46.93 minutes |
| Average ED Length of Stay | 184.60 minutes |
| ED Admission Rate | 18.12% |

## Dashboard Visualizations
- Average ED wait time by arrival hour
- ED patient arrivals by hour
- ED encounters by acuity level
- Average ED length of stay by acuity level
- ED patient distribution by acuity level

## Project Workflow
1. Prepare the synthetic emergency department dataset.
2. Load and examine the data using PostgreSQL and SQL.
3. Develop analytical measures and visuals in Power BI.
4. Design a dashboard for exploring emergency department operations.
5. Publish the project files and documentation on GitHub.

## Power BI File
Download `Hospital_ED_Analytics_Dashboard.pbix` from this repository and open it using Power BI Desktop.

## Data Disclaimer
This project uses synthetic, illustrative healthcare data. The statistics do not represent actual hospital performance or real patient outcomes.

## Skills Demonstrated
SQL, PostgreSQL, Power BI, DAX, data preparation, KPI development, data visualization, dashboard design, and analytical storytelling.
